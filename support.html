부적절한 노트 신고
노트를 열고 오른쪽 위 ⋯ → 「신고하기」를 누르고 까닭을 고릅니다. 신고한 노트는 곧바로 내 화면에서 사라지고, 운영자가 24시간 안에 확인합니다. 신고가 3건 쌓이면 확인 전까지 모든 사람에게서 숨겨집니다.
사용자 차단
노트를 열고 ⋯ → 「이 사용자 차단」. 그 사람의 노트가 더는 보이지 않습니다. 차단은 설정(톱니바퀴) → 차단한 사용자에서 풀 수 있습니다.
저작권 침해 신고
내 저작물이 허락 없이 올라왔다면 ⋯ → 「신고하기 → 저작권 침해」를 누르거나 메일로 노트 제목과 원저작물을 알려 주세요. 확인 즉시 내립니다.

자주 묻는 것

노트를 올리려면? 내 노트에서 노트나 폴더를 길게 눌러 「YourNote에 올리기」. 처음 한 번 약관에 동의하고, iCloud에 로그인되어 있어야 합니다.

올린 노트를 내리려면? 둘러보기 → 「내가 올린 노트」 → 노트 열기 → ⋯ → 「올린 노트 내리기」.

여러 PDF나 폴더를 한꺼번에 가져오려면? 내 노트의 ＋ → 「PDF·폴더 가져오기」에서 여러 개를 고르거나 폴더를 고릅니다. 파일 앱에서 여러 개를 골라 공유 → YourNote로 보내도 모두 들어옵니다.

스캔한 PDF의 글자가 안 잡혀요. 가져오면 자동으로 글자를 알아봅니다. 바로 안 되면 그 쪽을 길게 눌러 다시 알아보게 합니다.
